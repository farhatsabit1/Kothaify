# ⌨️ Kothaify

A highly optimized, ultra-lightweight, and completely portable phonetic Bangla typing utility for Windows. Write Bangla seamlessly using standard English phonetics. 

Unlike traditional offline tools, this utility utilizes a live connection to process and translate your inputs word-by-word with maximum precision.

---

## 🚀 Core Features

* **⚡ 100% Portable:** Runs instantly as a standalone `.exe` file. No setups, no configuration wizards, and zero registry bloat.
* **🌐 Live Processing (Wi-Fi Required):** Connects to a cloud-based layout engine to ensure highly accurate, context-aware phonetic dictionary matching.
* **⌨️ Spacebar Word-by-Word Translation:** Type your word in English phonetics and simply hit the `Spacebar`. The app instantly converts that specific word into Bangla on the fly.
* **🪶 Ultra-Lightweight:** Compressed to a tiny footprint of just **26 MB**, keeping your local system footprint incredibly small.
* **🕵️ System Tray Integration:** Operates quietly in the background. Right-click the icon in the Windows taskbar system tray to access settings or exit.
* **🔗 Universal Layout Compatibility:** Works across all Windows applications including Microsoft Word, Notepad, Chrome, Discord, and system search.

---

## 📥 Installation & Usage Guide

Since this application is fully portable, getting started takes less than 10 seconds:

1. Connect your Windows PC to **Wi-Fi or an active internet connection** (required for word processing).
2. Head over to the Releases section on the right side of this page.
3. Download the latest version of the executable file (Kothaify.exe).
4. Move the downloaded file to your preferred folder (e.g., `Desktop`, `Documents`, or `Program Files`).
5. Double-click the file to launch it. 

### ⌨️ How to Type Phonetically
1. Ensure your internet connection is active.
2. Open any text editor (like Notepad) and start typing your word using Roman letters.
3. **Press the Spacebar.** Pressing the Spacebar signals that you have completed 1 word, and the utility will immediately translate it into Bangla.

| English Input | Trigger Action | Bangla Output |
| :--- | :--- | :--- |
| `ami` | Press `Spacebar` | আমি |
| `bangla` | Press `Spacebar` | বাংলা |
| `bhalo` | Press `Spacebar` | ভালো |
